1. USB 키보드 연결

USB HID 장치를 선택하면 CH57x Standard 형식의 설정 인터페이스와 키·노브 구성을 자동 확인합니다. 다른 VID/PID라도 정상 응답을 받으면 화면이 자동으로 바뀝니다. 다른 프로토콜 또는 읽기 응답이 불완전한 제품에는 저장하지 않습니다.

연결되지 않음

Windows에 보이는 MI_01은 일반 키보드 인터페이스일 수 있습니다. 설정 통신은 FF00:0001의 제조사 전용 HID 인터페이스가 필요합니다. USB ID는 컴퓨터가 아닌 장치에서 보고하는 값입니다.

Chrome/Edge의 http://localhost 또는 HTTPS에서 열어야 합니다. 제조사 설정 프로그램이 실행 중이라면 먼저 종료하세요.

2. 기존 설정 읽기

장치 선택 창의 제품명은 브라우저/USB 펌웨어에서 제공하므로 바꿀 수 없습니다. 연결 후 웹페이지에는 CH57x 키/노브 개수 및 USB ID를 표시합니다. 처음 연결할 때 레이어 1을 읽고 물리 키와 노브 수에 맞는 편집 버튼을 생성합니다. 설정을 모두 읽어야 쓰기 기능이 활성화됩니다. 레이어 2/3의 실제 전환은 제품 펌웨어에 따라 다릅니다.

KNOB 1클릭하여 세 동작 보기
KNOB 1 설정

선택한 KEY 1 · 장치에서 설정을 읽으면 현재 동작이 여기에 표시됩니다.

백업 JSON을 선택하면 복원 대상 슬롯과 제한 사항을 표시합니다. 백업을 읽기만 해서는 기기 설정이 바뀌지 않습니다.

3. 선택한 입력 변경

KEY 1을 편집합니다. 아래 값은 새로운 설정이며, 기존 설정을 읽은 경우 각 입력을 선택하면 아래 편집기에 자동으로 표시됩니다.

같은 Step의 왼쪽/오른쪽 수정키는 일반 키와 동시에 입력됩니다. 각 Step은 위에서 아래 순서로 실행됩니다.
선택 박스와 직접 입력창은 서로 연동됩니다. 키를 선택하면 해당 Step이 즉시 갱신됩니다. 기존처럼 일반 키 이름을 직접 입력할 수도 있습니다.한 Step에는 조합키 여러 개와 일반 키 하나를 지정할 수 있습니다. Ctrl만 단독으로 누르는 입력은 현재 Standard 프로토콜에서 지원이 확인되지 않았습니다.
지연은 0~6000ms, 1ms 단위입니다. 이 모델은 각 Step에 독립된 지연값을 저장하지 못하고 매크로 전체에 공통 지연값만 지원합니다. 서로 다른 값이 있으면 저장을 차단합니다. 장치의 기존 지연값은 읽기로 확인할 수 없습니다.
위 버튼으로 편집하면 자동 갱신됩니다. 이 텍스트를 직접 편집하면 Step 목록에도 반영됩니다.

미리보기를 만든 뒤 내용을 확인하고 저장하세요.

v7.6.3: 기기가 보고한 각 KEY 및 노브 슬롯을 정상적으로 읽은 경우에만 저장할 수 있습니다. 읽기 응답이 누락되거나 충돌한 슬롯은 자동으로 저장이 차단됩니다. 저장 시 해당 슬롯의 원래 설정이 덮어써집니다. 먼저 JSON 백업을 권장합니다. 읽어온 설정과 저장 후 다시 읽은 설정을 비교합니다. 처음에는 하나의 키부터 테스트하세요.

4. LED 조명 설정 (키·매크로 저장과 별개)

현재 선택한 레이어에 적용됩니다. 색상은 지정된 8가지 색상 중 선택할 수 있으며, 임의 RGB/키별 독립 색상은 이 프로토콜에서 지원하지 않습니다.

항상 켜짐 · 빨강
기기 연결 후 이용 가능

LED 저장은 FE B0 조명 패킷과 FD FE FF 확정 명령만 전송합니다. 키·노브 설정과 매크로, 지연시간은 전송하거나 변경하지 않습니다. 현재 LED 값은 이 기기의 읽기 응답에 포함되지 않아 저장 후 자동 되읽기 검증은 할 수 없습니다.

연결 전입니다.

연결이 되지 않으면 이 로그를 복사해 전달하면 통신 문제를 좁힐 수 있습니다. 민감한 내용이 아니라 USB 응답 코드와 설정 기록만 남기며 자동으로 업로드하지 않습니다.

지원 범위: 제조사 필터 없는 HID 검색, 응답 구조가 일치하는 CH57x-1(Standard) 프로토콜 제품, 기기 응답에 따른 동적 키·노브 배열. 별도 프로토콜 제품은 설정이 차단됩니다. 미등록 장치는 전체 슬롯 검증 후 키 설정만 허용합니다. 프로토콜 근거: CH57x HID 프로토콜 문서 / 514C:8851 실제 장치 검증 기록. 이 웹페이지는 특정 제조사의 공식 프로그램이 아닌 비공식 CH57x 표준 프로토콜 설정기입니다. 기기 실물 검증 전이므로 동작을 보장하지 않습니다.
